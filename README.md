# 昼夜外观

独立的简体中文 macOS 菜单栏应用，用来手动或定时切换系统浅色／深色外观。它不包含 NightOwl 的程序或代理网络组件。适用于 macOS 13 或更新版本的 Apple Silicon Mac。

## 安装

打开 `Dist/昼夜外观.dmg`，将「昼夜外观.app」拖到「应用程序」。从应用程序文件夹启动后，点击菜单栏的太阳／月亮图标。

首次切换外观时，macOS 可能要求允许本应用控制「系统事件」。这是执行系统外观切换所需的权限。若拒绝，可在「系统设置 → 隐私与安全性 → 自动化」中调整。

默认定时为 19:00 切到深色、07:00 切到浅色；菜单中可以修改。手动切换会暂停自动切换，直到再次启用。登录启动选项只在下次登录后生效，请在应用程序文件夹安装后再启用。

在菜单中选择「设置切换快捷键…」。若要使用纯修饰键组合，在「按键」中选「无（仅用两个修饰键）」，恰好勾选两个修饰键，例如 Control + Command（⌃⌘），然后点「保存」。按下第二个修饰键时切换一次；松开后才能再次触发。也可以选择字母或数字，搭配修饰键使用。再次点「启用快捷键」可以暂停或恢复。字母／数字快捷键若被占用，应用会提示重新选择。它基于实体键位置，切换键盘布局后显示字符可能与实际键位不同。

纯修饰键组合需要 macOS 的「输入监控」权限。系统询问时请允许「昼夜外观」；若未生效，在「系统设置 → 隐私与安全性 → 输入监控」中允许后，退出并重新打开本应用。应用只监听修饰键状态变化，不读取字母或数字按键。纯修饰键组合可能同时触发其他应用已有的操作，请选择自己用起来顺手的组合。

本应用使用本地临时签名，没有 Apple 开发者公证。macOS 首次打开时可能需要在「系统设置 → 隐私与安全性」中选择「仍要打开」。

## 重新构建

在本目录依次运行 `./build.sh` 和 `./package.sh`，分别构建应用、生成 `Dist/昼夜外观.dmg`。需要 Xcode 命令行工具。源码位于 `Sources/main.swift`，图标原稿位于 `Assets/DayNight-1024.png`；用 `python3 make_icon.py` 可以重新生成多尺寸图标，需安装 Pillow。

## 限制

当前版本提供手动切换、固定时间自动切换、全局快捷键及登录启动。没有按日出／日落切换、逐应用强制外观或猫头鹰音效。系统外观切换由 macOS 的「系统事件」执行。
